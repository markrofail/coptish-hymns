# Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task by task.

**Goal:** Draw a parsed string as the string view, and run it as the `render` node. PLAN.md Phase 0 item 4: done when the demo phrase renders from its text form, locked by snapshot tests.

**Architecture:** `flatten` gains spans saying which events belong to each motif and repeat. A new `hymnstring/notation/renderer.py` turns flat events into SVG, one `<svg>` per phrase, with all geometry computed in logical coordinates and passed through one x-mapping so right-to-left phrases mirror in one place. The `render` node writes an HTML page of those SVGs.

**Tech Stack:** Python 3.12 standard library only. `xml.etree` in tests. No new dependencies.

**Spec:** PLAN.md Phase 0 item 4; CONTEXT.md sections 2 and 3; `hymnstring/notation/SPEC.md`; `reference/string_demo.svg` as a style reference only. The table in CONTEXT.md section 3 is authoritative for lengths.

## Review Focus

1. Very short stretches, such as `>1{* ^ * ^ * ^ *}`: a slope must never run backwards past the bead it leaves.
2. Pauses at the edges: `1 .2` ending on a pause, and `1 .2 v 1` with a move straight after one.
3. Crowded lyrics: three syllables in `>2{ⲧⲓ:* ^ ⲛⲉ:* v ⲣⲁ:*}` must not overlap, and combining marks such as a jinkim must count as no width.
4. Annotations colliding: `#1[(1)x3 ^ 2]` and `(#1[1 ^ 1])x2` must keep labels and brackets apart.
5. A right-to-left phrase: geometry mirrors, but lyric letters stay in reading order and aren't reversed.

Each has a test in Task 1.

#### Constants, at the top of `renderer.py`

`UNIT_PX = 12.5` (a half note), `LEVEL_PX = 20`, `MARGIN_X = 40`, `STROKE = 3`, `BEAD_R = 3`, `SLOPE_PX = 6`, `TEAL = "#1D9E75"`, `GRAY = "#888780"`, `LABEL = "#5F5E5A"`, `INK = "#2C2C2A"`, `ADDED = "#C8402A"`, `SILENT = "#A3A29C"`, `MOTIF_COLOURS = ("#7F77DD", "#D85A30", "#378ADD", "#BA7517", "#D4537E", "#639922")`, `LYRIC_SIZE = 14`, `LABEL_SIZE = 12`, `LYRIC_GAP = 3`. Font family: `-apple-system, 'Helvetica Neue', Helvetica, Arial, 'Noto Sans Coptic', sans-serif`.

#### Geometry

Flatten `phrase.items` with level 0. The phrase's join is not drawn. Each phrase's lowest note is level 0, so `y = base - LEVEL_PX * (level - lowest)`.

Bead `x = MARGIN_X + unit * (sum of lengths before the event)`. `x_end = MARGIN_X + unit * total`. The stretch of event i runs from its `x` to the next event's `x`, or `x_end`. Width is `MARGIN_X` past the furthest of `x_end` and the last lyric's estimated right edge.

For right-to-left, every x passes through `X(x) = width - x` in one place. Paths use absolute commands only, so this is enough. Lyrics get `text-anchor="end"` and `direction="rtl"`, and their letters stay in reading order. The repeat label's arrows become `↖` and `↙`.

The canvas shifts down so the highest annotation is 12 px from the top. The lyric baseline is 28 px below the lowest level, and the canvas ends 14 px below that. `width` and `height` attributes are twice the `viewBox`, with `role="img"`, a `<title>` of `Phrase <id>`, and a white `<rect>` first.

Numbers print with at most 2 decimals and no trailing zeros, through one helper.

#### What each event draws

Elements carry a `class`, and tests find them by it. Paths come first, then beads, then annotations, then lyrics.

A stretch ends in the move into the next event, when that event is a `FlatNote` with a `move`:

- Smooth: the stretch runs straight to `x_next - s`, where `s = min(SLOPE_PX, stretch / 2)`. A `class="slope"` path is `M x_next-s y C x_next-s/2 y x_next-s/2 y_next x_next y_next`.
- Abrupt with a change: straight to `x_next`, then `class="corner"`, a vertical path to `y_next`.
- Bare `!`: straight to `x_next`, then `class="tick"`, a vertical path from `y - 6` to `y + 6`, stroke width 1.5.

The straight part, `class="stretch"`, depends on the event:

- Note: solid, stroke 3, round caps and joins.
- Vibrato: `class="wave"`. Half-waves 3 px wide, built as `Q` then `T` in absolute coordinates with the control point 7 px up, as many whole half-waves as fit, then `L` to the end of the straight part.
- Fast: `class="fast"`, stroke 1.5, `stroke-dasharray="3 2.5"`, `stroke-linecap="butt"`.
- Pause: `class="pause"`, stroke `GRAY`, stroke 1.5, `stroke-dasharray="0.5 4"`.

Every note gets a `class="bead"` circle.

Colour: a note's stretch and bead take the colour of the innermost motif holding it, else `TEAL`. A motif's colour is `MOTIF_COLOURS[(label - 1) % 6]`, the same for shifted occurrences. A move into event j takes the colour of the innermost motif with `first_event < j < end_event`, else `TEAL`, so moves into and out of a motif are teal. For the demo the moves are, in order of target event 1, 2, 3, 5, 6, 7, 10, 11, 12, 13: purple, purple, teal, teal, teal, teal, teal, purple, purple, teal.

#### Annotations

Place them so none overlap, in this order: breath marks, then motifs, then repeats, smaller spans before larger. For each, `base` starts at the y of the highest level in its span, and rises to the top of anything already placed that overlaps it in x.

- Breath, over the middle of a pause: `class="breath"` group, a dot of radius 2.5 at `base - 16`, and a tail path `M cx+2.3 cy+0.5 Q cx+2.8 cy+5.5 cx-1.2 cy+8.5`. Its top is `base - 20`.
- Motif: `class="motif-label"` text, centred over the span, baseline `base - 12`, top `base - 24`, fill `LABEL`. Text is `①` to `⑳`, or `#21` past that, followed by the shift such as `+1` or `-2`.
- Repeat: `class="repeat-bracket"` path, from the first bead to the end of its last event, feet at `base - 16`, line at `base - 22`, stroke `LABEL`, width 1. `class="repeat-label"` text centred above, baseline `base - 30`, top `base - 42`. Text is `×3`, `×3 ↗`, `×3 ↘`, `×3 ↗2`, `×3 ↘2`.

#### Lyrics

`class="lyric"` text at the note's bead on the lyric baseline, `LYRIC_SIZE`, fill `INK`. Added letters are a `<tspan fill=ADDED>`, silent ones a `<tspan fill=SILENT>`. A fast note's lyric gets `text-decoration="underline"`. A vowel label is `class="vowel"`, `(a)`, `LABEL_SIZE`, fill `LABEL`. Escape all text.

`hymn_unit`: the smallest unit at least `UNIT_PX`, rounded up to 2 decimals, such that in every phrase each lyric's estimated width plus `LYRIC_GAP` fits before the next lyric. Estimated width is `0.62 * size * n`, where `n` counts characters that aren't combining marks. A vowel label counts its two brackets. The demo must stay at exactly `12.5`.
